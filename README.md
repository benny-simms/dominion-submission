

### Model Architecture
Yolo26 architecture pretrained on the COCO image detection dataset and finetuned on the VisDrone aerial drone dataset.


### First Time Setup:

**1. Setup the model environment**
```bash
conda env create -f environment.yaml
conda activate dominion-submission
```

**2. Download the VisDrone Dataset**
```bash
python ./scripts/download_data.py
```
